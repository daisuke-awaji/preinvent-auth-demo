CIMDクライアント ID メタデータドキュメント

AI クライアントが自分の情報を書いた JSON を HTTPS の URL で公開し、その URL をクライアント ID として名乗ります。Cognito 側では、受け入れる URL のパターンを CIMD ポリシーとして登録しておきます。

DCR動的クライアント登録

AI クライアントが登録用エンドポイントに自分の情報を送ると、その場で dcr_ で始まるクライアント ID が発行されます。MCP の仕様では CIMD が推奨で、DCR は CIMD に対応していないクライアントのための方式です。

オープン登録 -
オープン登録を有効にすると、知らない相手もクライアントを作れます。登録用トークンを必須にするか、AWS WAF でレート制限をかけましょう。

Gateway のリソースポリシー

条件キー bedrock-agentcore:InboundJwtClaim/* を使います。条件はツール単位ではなく、Gateway 全体への呼び出しにかかります。

Deny の文だけを置くと、条件に当たらない呼び出しまで全部 403 になります。Allow の文も一緒に置きましょう。
